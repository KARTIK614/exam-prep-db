## The Mock Test Analysis System (7-Step Deep Analysis)

After EVERY mock test, do this. No exceptions. A mock without analysis is wasted time.

### Step 1: The Snapshot

| Metric | Value | Target |
|--------|-------|--------|
| Overall Score | ___/100 | 70+ |
| Attempted | ___/100 | 90+ |
| Correct | ___ | — |
| Wrong | ___ | <15 |
| Unattempted | ___ | <10 |
| Net Score (Correct - Wrong/3) | ___ | 65+ |

### Step 2: Time vs Accuracy Audit

| Section | Time Spent | Questions Attempted | Accuracy % | Time/Q |
|---------|------------|---------------------|------------|--------|
| Rajasthan History | | | | |
| Rajasthan Geography | | | | |
| Current Affairs | | | | |
| General Science | | | | |
| Reasoning | | | | |
| Quant/DI | | | | |

**Red flag:** Spending >2 min/question with <50% accuracy = WASTED TIME
**Green flag:** Spending <45 sec/question with >80% accuracy = EFFICIENT

### Step 3: Error Categorization (The 5-Bucket System)

For EVERY wrong answer, categorize:

| Error Type | Code | Example |
|------------|------|---------|
| **Concept Gap** (didn't know the concept) | CG | Didn't know OSI layers, couldn't answer any question on it |
| **Memory Lapse** (knew it but forgot) | ML | Know Sambhar Lake but forgot which districts |
| **Misread** (read question/options wrong) | MR | Read "NOT correct" as "correct" |
| **Calculation** (math error) | CA | Formula right, arithmetic wrong |
| **Time Pressure** (rushed, would've gotten right with more time) | TP | Last 10 questions, guessed 6 |

Track the distribution:
```
CG: ____ (These need CONCEPT STUDY)
ML: ____ (These need SPACED REPETITION)
MR: ____ (These need READING DISCIPLINE)
CA: ____ (These need CALCULATION PRACTICE)
TP: ____ (These need SPEED BUILDING)
```

### Step 4: Topic Weakness Score

For each topic, calculate:

```
Weakness Score = (Wrong Answers × 2) + (Unattempted × 1) + (Slow Correct × 0.5)
```

Sort topics by Weakness Score descending → This IS your priority order.

### Step 5: Correct Answer Audit

Check your CORRECT answers too:
- **Did you actually KNOW it, or did you GUESS?** (Lucky guesses = future wrong answers)
- **Did you spend too MUCH time on it?** (Time-inefficient correct = needs speed practice)
- **Was your reasoning path correct?** (Right answer, wrong logic = ticking time bomb)

### Step 6: Pattern Recognition

After 3+ mocks, look for patterns:
- Same topic wrong every time? → **Deep concept gap — study from scratch**
- Different topics but same error type (e.g., always MR)? → **Process problem, not knowledge problem**
- Always weak in the last 20 questions? → **Stamina/timing issue, not knowledge issue**

### Step 7: Action Plan

For each identified weak topic, write SPECIFIC actions:
- ❌ BAD: "Study Networking more"
- ✅ GOOD: "Solve 30 MCQs on OSI Model layers + TCP/IP protocols + subnetting from YCT Set 3 & 4. Target: 80% accuracy by Friday."

## The Error Log System (3R Protocol)

Maintain a simple spreadsheet or notebook with:

```
DATE | TEST | Q.NO | TOPIC | MY ANSWER | CORRECT ANSWER | ERROR TYPE | ROOT CAUSE | CORRECT CONCEPT (1-line)
```

### 3R Protocol:
1. **RECORD** — Log every error within 24 hours of the mock test
2. **REVIEW** — Every Sunday, review the week's error log. Spot patterns.
3. **REDO** — Re-solve the same question at Day 3, Day 7, and Day 15 intervals

> **Pareto Principle in errors:** ~20% of your weak topics cause ~80% of your wrong answers. The error log reveals exactly which 20%.

## The Active Recall + Spaced Repetition Playbook

### For Each Topic You Study:

#### Day 1: LEARN (2 hours)
1. **Pre-test (10 min):** 10 MCQs on the topic BEFORE studying. Cold attempt. This primes your brain.
2. **Active reading (45 min):** Read concept notes. After EACH sub-topic, close the book and write what you remember.
3. **Teach-back (15 min):** Explain the concept out loud as if teaching a class. If you stumble, re-read that part.
4. **MCQ Practice (45 min):** 30-40 MCQs. No looking at notes.

#### Day 3: RECALL (30 min)
- 20 MCQs from the same topic. No warm-up, no review first.
- Score. If <70%, mark topic for re-study.

#### Day 7: REINFORCE (20 min)
- 15 MCQs mixing this topic + previously studied topics (interleaving)
- This forces your brain to discriminate between concepts

#### Day 15: RETAIN (15 min)
- 10 MCQs, exam-style, timed
- This is the final check — if you score <70% here, the topic goes back to the weak list

### Spaced Repetition Flashcard System

Create digital (Anki) or physical flashcards for:
- **Dates & Events** (e.g., "Haldi Ghati Battle → 1576")
- **Formulas** (e.g., "Escape Velocity → 11.2 km/s")
- **Definitions** (e.g., "Foreign Key → Column linking to Primary Key of another table")
- **OSI Layers** (e.g., "Layer 6 → Presentation → Translation, Encryption, Compression")
- **Rajasthan Facts** (e.g., "Zawar mines → Udaipur → Zinc")

Review schedule: 1 day → 3 days → 7 days → 14 days → 30 days

## Critical Rules for Success

### 1. The 40% Floor Rule
Before chasing 80+, ensure you can consistently score **40%+ in BOTH papers separately** in every mock. One paper below 40% = automatic disqualification. Check this after every mock.

### 2. The Negative Marking Survival Rule
With -1/3 negative marking:
- **Blind guessing** (no elimination) = Expected value is NEGATIVE
- **One elimination** (4→3 options) = Expected value ~0 (barely worth it)
- **Two eliminations** (4→2 options) = Expected value POSITIVE (TAKE THE SHOT)
- **Sure answer** = ALWAYS attempt

> **Strategy:** Never leave more than 10 questions unanswered. If you can eliminate 2 options, attempt it. If you can eliminate only 1, skip unless you have strong intuition.

### 3. The Interleaving Rule
Don't study the same subject for 4 hours straight. Mix:
- Morning: Rajasthan History (memory-heavy)
- Evening: Computer Networking (conceptual)
- Night: Reasoning practice (skill-based)

Mixing subject types prevents mental fatigue and improves retention.

### 4. The 80/20 Study Rule
20% of topics give 80% of marks. The Diagnostic Tests reveal WHICH 20%.
- Don't spend 10 hours on "Ancient Rajasthan" (3-4 questions) when "Art & Culture" (8-10 questions) is weak.
- Don't spend 20 hours on "IoT" (2-3 questions) when "DBMS" (8-10 questions) needs work.

### 5. The "Arrey Yaar" List
Maintain a special list of questions you got wrong but KNEW the answer to ("Arrey yaar, I KNEW this!"). These are your most expensive errors — they cost marks you already earned through study. Fixing these is the fastest way to gain 5-10 marks.

## The Morning-of-Exam Protocol

### Night Before:
- No new topics. No heavy studying.
- Review your "Arrey Yaar" list (most expensive past errors)
- Review formula sheet + key dates (30 min max)
- Pack: Admit card, ID proof, blue ballpoint pens (×3), water bottle
- Sleep by 10:00 PM

### Exam Morning:
- Wake up 6:00 AM
- Light breakfast (no heavy/oily food)
- 15-min flashcard review (only the ones you frequently forget)
- Reach center 45 min before reporting time
- DO NOT discuss topics with other candidates outside the center
- In exam hall: Deep breaths. You've done the work.

### During the Exam — 3-Pass Method:
```
PASS 1 (60 min):  "Sure Shot" questions
                  → Attempt only questions you're 90%+ confident about
                  → Mark unclear ones with a light pencil dot
                  → Target: 50-55 questions cleared

PASS 2 (40 min):  "Think & Eliminate" questions
                  → Return to marked questions
                  → Eliminate 2 options → attempt
                  → Eliminate only 1 → skip (unless strong intuition)
                  → Target: 30-35 more questions cleared

PASS 3 (20 min):  "Calculated Risk" questions
                  → Only if you can eliminate at least 1 option
                  → Never blind-guess
                  → OMR darkening check: all bubbles properly filled?
                  → Target: 5-10 more questions attempted
```
