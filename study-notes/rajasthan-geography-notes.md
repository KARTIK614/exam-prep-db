## 2. Physiographic Divisions (भौतिक प्रदेश)

Rajasthan is divided into **4 major physiographic divisions**:

### 2.1 Western Arid / Desert Region (पश्चिमी रेगिस्तानी प्रदेश)
- **Area:** ~61% of Rajasthan (LARGEST division)
- **Extent:** Western border to the Aravalli range
- **Features:** Sand dunes / धोरे, Barchans / बरखान, Longitudinal dunes
- **Key Districts:** Jaisalmer / जैसलमेर, Barmer / बाड़मेर, Bikaner / बीकानेर, Jodhpur / जोधपुर (western part), Nagaur / नागौर (western), Churu / चूरू, Sri Ganganagar / श्रीगंगानगर (southern), Hanumangarh / हनुमानगढ़ (southern)
- **Thar Desert / थार मरुस्थल:** India's largest desert, ~2,05,000 sq km (~62% in Rajasthan)

#### Sub-Divisions:
1. **Arid Sand-dune Free Region (शुष्क बालुका स्तूप मुक्त प्रदेश):** Western Jaisalmer
2. **Sand-dune Region (बालुका स्तूप युक्त प्रदेश):** Jaisalmer-Barmer
3. **Luni Basin (लूनी बेसिन):** Jalore / जालोर, Pali / पाली area
4. **Shekhawati Region (शेखावाटी प्रदेश):** Sikar / सीकर, Jhunjhunu / झुंझुनूं, Churu / चूरू
5. **Ghagghar Plain (घग्घर मैदान):** Sri Ganganagar, Hanumangarh
6. **Nagaur Upland (नागौरी उच्च भूमि):** Nagaur area
7. **Inland Drainage Region (आंतरिक जल निकास प्रदेश):** Sambhar Lake / सांभर झील area

### 2.2 Aravalli Mountainous Region (अरावली पर्वतीय प्रदेश)
- **Area:** ~9% of Rajasthan
- **Direction:** SW to NE (Gujarat → Rajasthan → Haryana → Delhi)
- **Total Length:** ~692 km (Rajasthan portion ~550 km)
- **Extent:** Sirohi / सिरोही to Alwar / अलवर / Bharatpur / भरतपुर

### 2.3 Eastern Plains Region (पूर्वी मैदानी प्रदेश)
- **Area:** ~23% of Rajasthan
- **Extent:** East of Aravalli to the state's eastern border
- **Rivers:** Chambal / चंबल, Banas / बनास, Mahi / माही
- **Key Districts:** Bharatpur / भरतपुर, Dholpur / धौलपुर, Karauli / करौली, Sawai Madhopur / सवाई माधोपुर, Tonk / टोंक, Kota / कोटा, Bundi / बूँदी, Baran / बाराँ, Jhalawar / झालावाड़, Bhilwara / भीलवाड़ा (eastern)

#### Sub-Divisions:
1. **Banas-Chambal Basin (बनास-चंबल बेसिन)**
2. **Middle Mahi Basin (मध्य माही बेसिन)**
3. **Chambal Badlands / Ravines (चंबल बीहड़ प्रदेश)**

### 2.4 South-Eastern Plateau Region (दक्षिण-पूर्वी पठारी प्रदेश)
- **Area:** ~7% of Rajasthan (SMALLEST division)
- **Also Known As:** Hadoti Plateau / हाड़ौती का पठार
- **Key Districts:** Kota / कोटा (southern), Bundi / बूँदी, Jhalawar / झालावाड़, Baran / बाराँ
- **Features:** Mukundra Hills / मुकुंदरा पहाड़ियाँ, Black soil region / काली मृदा

### Geographical Significance of Aravalli (अरावली का भौगोलिक महत्व)
1. **Climate Divider (जलवायु विभाजक):** Creates a rain-shadow — eastern Rajasthan gets 100+ cm rainfall, western Rajasthan gets <25 cm
2. **Drainage Divider (अपवाह विभाजक):** Western rivers flow to Arabian Sea / inland drainage; eastern rivers flow to Bay of Bengal
3. **Natural Wall (प्राकृतिक दीवार):** Prevents Thar Desert from expanding eastward — called **"Lifeline of Rajasthan / राजस्थान की जीवन रेखा"**
4. **Mineral Wealth (खनिज भंडार):** Rich source of zinc, lead, copper, marble
5. **Forest Wealth (वन संपदा):** Dense forests (Udaipur, Sirohi, Rajsamand)

## 5. Climate (जलवायु)

### General Features (सामान्य विशेषताएँ)

| Detail (विवरण) | Fact (तथ्य) |
|-----------------|-------------|
| **Climate Type (जलवायु प्रकार)** | Tropical Arid / Semi-Arid (उष्ण कटिबंधीय शुष्क/अर्द्ध-शुष्क) |
| **Average Rainfall (औसत वर्षा)** | ~57 cm (575 mm) |
| **Highest Rainfall** | Jhalawar / झालावाड़ (~100 cm) |
| **Lowest Rainfall** | Jaisalmer / जैसलमेर (~16-20 cm) |
| **Hottest Place (सबसे गर्म स्थान)** | Churu / चूरू & Sri Ganganagar / श्रीगंगानगर (50°C+ in summer) |
| **Coldest Place (सबसे ठंडा स्थान)** | Mount Abu / माउंट आबू (down to 0°C in winter) |

### Climatic Zones (Köppen Classification / कोपेन वर्गीकरण)

| Zone (प्रदेश) | Region (क्षेत्र) | Rainfall / वर्षा (cm) |
|---------------|------------------|----------------------|
| **Hyper-Humid (अति-आर्द्र)** | Jhalawar / झालावाड़, Banswara / बाँसवाड़ा | 100+ |
| **Humid (आर्द्र)** | Kota / कोटा, Baran / बाराँ, Udaipur / उदयपुर | 80-100 |
| **Semi-Humid (अर्द्ध-आर्द्र)** | Jaipur / जयपुर, Bharatpur / भरतपुर, Alwar / अलवर | 60-80 |
| **Semi-Arid (अर्द्ध-शुष्क)** | Ajmer / अजमेर, Jodhpur / जोधपुर, Pali / पाली | 40-60 |
| **Arid (शुष्क)** | Jaisalmer / जैसलमेर, Barmer / बाड़मेर, Bikaner / बीकानेर | 20-40 |
| **Hyper-Arid (अति-शुष्क)** | Western Jaisalmer / पश्चिमी जैसलमेर | <20 |

### Monsoon (मानसून)
- **South-West Monsoon** brings rainfall (June-September)
- Both **Arabian Sea branch** and **Bay of Bengal branch** contribute
- Rainfall **increases from West to East** in Rajasthan
- **Mawath / मावठ** — Winter rainfall (January-February), beneficial for Rabi crops / रबी फसल

### Seasons (ऋतुएँ)
1. **Summer / ग्रीष्म (March-June):** Temperature 32°C-48°C, "Loo" / लू (heat waves)
2. **Monsoon / वर्षा (July-September):** 90% of annual rainfall
3. **Winter / शीत (October-February):** Min temperature 0°C-10°C, cold waves / शीतलहर

## 6. Soils (मृदा)

### 6.1 Desert Soil (रेगिस्तानी मृदा)
| Detail | Fact |
|--------|------|
| **Region** | Western Rajasthan (Jaisalmer, Barmer, Bikaner, Jodhpur) |
| **Color** | Brownish-yellow, light grey |
| **Characteristics** | Low nitrogen & humus, high pH / alkaline |
| **Crops** | Groundnut / मूँगफली, Guar / ग्वार, Bajra / बाजरा (with irrigation) |

### 6.2 Red-Yellow Soil (लाल-पीली मृदा)
| Detail | Fact |
|--------|------|
| **Region** | Eastern & Southern Rajasthan (Udaipur, Dungarpur, Banswara) |
| **Color** | Red-Yellow (due to iron oxide / लौह ऑक्साइड) |
| **Characteristics** | Acidic, low nitrogen |
| **Crops** | Maize / मक्का, Jowar / ज्वार, Pulses / दलहन |

### 6.3 Black Cotton Soil (काली मृदा) — Regur
| Detail | Fact |
|--------|------|
| **Region** | Hadoti / हाड़ौती region (Kota, Bundi, Jhalawar, Baran) |
| **Color** | Black / काली |
| **Characteristics** | High water retention, sticky when wet |
| **Crops** | Cotton / कपास, Wheat / गेहूँ, Soybean / सोयाबीन |

### 6.4 Alluvial Soil (जलोढ़ मृदा)
| Detail | Fact |
|--------|------|
| **Region** | North-Eastern plains (Sri Ganganagar, Hanumangarh, Bharatpur, Dholpur) |
| **Color** | Light brownish-grey |
| **Characteristics** | MOST fertile, deposited by rivers |
| **Crops** | Wheat / गेहूँ, Rice / धान, Sugarcane / गन्ना, Mustard / सरसों |

### 6.5 Mountainous Soil (पहाड़ी मृदा)
| Detail | Fact |
|--------|------|
| **Region** | Aravalli mountainous belt |
| **Characteristics** | Rocky, shallow, low fertility |
