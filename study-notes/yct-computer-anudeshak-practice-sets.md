## Subject-Wise Important Questions & Solutions

### A. COMPUTER FUNDAMENTALS

#### Number Systems
**Q.** Decimal number 12 in binary is:
(A) 1110 (B) 1100 (C) 1010 (D) 1000
**Ans: (B) 1100**
```
2 | 12 | Remainder
2 |  6 | 0 (LSB)
2 |  3 | 0
2 |  1 | 1
  |  0 | 1 (MSB)
Reading bottom-up: 1100
```

**Q.** Convert (12)₁₀ to binary:
**Ans:** 1100 (Divide by 2, read remainders from bottom)

#### Computer Memory
**Q.** Secondary memory is also known as:
(A) External memory (B) Cache memory (C) Internal memory (D) Primary memory
**Ans: (A) External memory / एक्सटर्नल मेमोरी**

**Q.** Which memory has the shortest access time?
(A) Cache Memory (B) Magnetic Bubble Memory (C) Magnetic Core Memory (D) RAM
**Ans: (A) Cache Memory — fastest memory unit in the computer hierarchy**

**Q.** On which type of ROM can data be written only once?
(A) PROM (B) EPROM (C) EEPROM (D) Flash ROM
**Ans: (A) PROM (Programmable Read Only Memory)**

**Q.** A set of circuits used to store one bit of data is known as:
(A) Register (B) Decoder (C) Encoder (D) Flip Flop
**Ans: (D) Flip Flop — a bistable digital logic circuit**

**Memory Hierarchy (Fastest to Slowest):**
Registers > Cache > RAM > Magnetic Disk > Optical Disk > Magnetic Tape

**Memory Units:**
```
8 bits     = 1 Byte
1024 Bytes = 1 KB
1024 KB    = 1 MB
1024 MB    = 1 GB
1024 GB    = 1 TB (Terabyte)
1024 TB    = 1 PB (Petabyte)
1024 PB    = 1 EB (Exabyte)
1024 EB    = 1 ZB (Zettabyte)
1024 ZB    = 1 YB (Yottabyte) — largest unit
```

#### Number Systems
**Q.** Two's complement is used to store:
(A) I/O device (B) Transistors (C) Zeros and ones (D) Negative numbers
**Ans: (D)** — Two's complement method is used to represent negative numbers in binary

#### Data Representation
**Q.** A microprocessor with 8-bit word length can process _____ bits data simultaneously.
(A) 4 (B) 8 (C) 16 (D) 32
**Ans: (B) 8**

### C. PROGRAMMING LANGUAGES

#### C Language
**Q.** Which storage class specifier is used to declare a 'register' variable?
(A) auto (B) static (C) register (D) extern
**Ans: (C) register** — suggests the compiler to store variable in CPU register; & operator cannot be applied to register variables

**Q.** Output of: `a = (int)21.3 / (int)4.5;`
**Ans: 5** (21/4 = 5 in integer division)

**Q.** In C, function prototype provides:
(A) Function name (B) Return type (C) Parameter list (D) All of these
**Ans: (D)** — Function prototype declares function name, return type, and parameters

#### C++ Language
**Q.** Which of the following is an Object-Oriented Programming language?
**Ans: C++** — supports classes, objects, inheritance, polymorphism, encapsulation, abstraction

#### Python
**Q.** Python output:
```python
class Acc:
    def __init__(self, id):
        self.id = id
acc = Acc(111)
print(acc.id)
```
**Ans: 111** — The instance variable `self.id` is set to 111

#### Java
**Q.** Java is a:
(A) Platform-dependent language
(B) Platform-independent language
(C) Both
(D) None
**Ans: (B)** — Java is platform-independent due to JVM (Write Once, Run Anywhere)

#### FORTRAN
**Q.** Full form of FORTRAN:
**Ans: Formula Translation** — first high-level programming language, developed by John Backus (IBM, 1957)

### D. DATA STRUCTURES & ALGORITHMS

**Q.** Popping an element from the stack means:
(A) Sorting elements (B) Adding new element (C) Removing an element (D) Searching an element
**Ans: (C) Removing an element** — Stack follows LIFO (Last In First Out)

**Stack Operations:**
- **PUSH** — Insert element at top
- **POP** — Remove element from top
- **PEEK/TOP** — View top element without removing

**Q.** Array (ऐरे) is:
**Ans:** A collection of similar data types stored in consecutive memory locations. Also called subscript variables.

**Q.** When an algorithm is written in the form of a programming language, it becomes a:
(A) Flowchart (B) Program (C) Pseudo code (D) Syntax
**Ans: (B) Program**

**Algorithm Properties:**
- Finiteness (निश्चितता)
- Definiteness
- Input/Output
- Effectiveness

### E. DATABASE MANAGEMENT SYSTEM (DBMS)

**Q.** Foreign Key (फॉरेन-की) is:
**Ans:** A column or set of columns that creates a relationship/link between data in two tables. References the Primary Key of another table.

**Q.** DDL (Data Definition Language) commands include:
**Ans: CREATE, ALTER, DROP, RENAME, TRUNCATE**

**DML (Data Manipulation Language):** SELECT, INSERT, UPDATE, DELETE
**DCL (Data Control Language):** GRANT, REVOKE
**TCL (Transaction Control Language):** COMMIT, ROLLBACK, SAVEPOINT

**Q.** Relationship between two different tables indicates:
**Ans:** Data contained in the two tables is related to each other in some way

### F. NETWORKING & COMMUNICATION

#### Network Topologies
**Q.** In Mesh Topology, the number of connections for n nodes:
**Ans: n(n-1)/2** — Each node connects to every other node

**Q.** In which topology is each node connected only to its nearest neighbors?
**Ans: Ring Topology** — If the ring breaks, the entire network fails

**Network Types:**
- **LAN** (Local Area Network) — limited geographic area
- **MAN** (Metropolitan Area Network) — city-wide
- **WAN** (Wide Area Network) — across countries/continents

#### OSI Model
**Q.** Which OSI layer translates, encrypts, and compresses data?
**Ans: Presentation Layer (Layer 6)**

| Layer | Name | Function |
|-------|------|----------|
| 7 | Application | User interface, HTTP, FTP, SMTP |
| 6 | Presentation | Translation, Encryption, Compression |
| 5 | Session | Session establishment, maintenance |
| 4 | Transport | TCP/UDP, end-to-end delivery |
| 3 | Network | IP addressing, routing |
| 2 | Data Link | MAC addresses, frames, error detection |
| 1 | Physical | Bits, cables, electrical signals |

#### Protocols
**Q.** Which protocol is used ONLY for sending emails?
**Ans: SMTP (Simple Mail Transfer Protocol)**

**Email Protocols:**
- **SMTP** — Sending email (outgoing)
- **POP3** — Receiving email (downloads from server)
- **IMAP** — Receiving email (keeps on server)

**Q.** TCP/IP full form:
**Ans: Transmission Control Protocol / Internet Protocol** — set of rules governing internet communication

**Q.** Internet works using TCP/IP protocol

**Q.** Which protocol does PPP use to identify the Network layer protocol?
**Ans: NCP (Network Control Protocol)** — PPP uses LCP (Link Control Protocol) and NCP

#### IP Addressing
**Q.** How many bits in an IPv4 address?
**Ans: 32 bits** (IPv6: 128 bits)

**Q.** DNS (Domain Name System) converts:
**Ans:** IP address into easy-to-remember names (e.g., www.google.com)

#### Network Devices & Concepts
**Q.** Intranet is:
**Ans:** A shared network within an organization providing connectivity to its staff

**Q.** ADSL (Asymmetric Digital Subscriber Line):
**Ans:** Provides high-speed internet over traditional telephone lines

**Q.** VoIP:
**Ans:** Voice over Internet Protocol — transmitting voice over IP networks

#### HTML & Web
**Q.** HTML full form:
**Ans: Hyper Text Markup Language** — developed by Tim Berners-Lee (1990-91)

**Q.** To open a link in a new browser window:
**Ans: TARGET="_BLANK"** in anchor tag

**Q.** `<td>` tag in HTML:
**Ans:** Defines a standard cell in an HTML table (text left-aligned by default)

**Q.** URL is:
**Ans:** Address of a webpage displayed on the internet (Uniform Resource Locator)

**Q.** Microsoft web publishing tool:
**Ans: Front Page** — WYSIWYG HTML editor (part of MS Office 1997-2003)

### G. NETWORK SECURITY

**Q.** SSL (Secure Socket Layer):
**Ans:** Creates an encrypted link between web server and browser for secure online transactions. Evolved into TLS (Transport Layer Security). Runs on top of TCP/IP.

**Q.** Netiquette (नेटिकेट):
**Ans:** Network + Etiquette — rules governing conduct for internet users

**Q.** Which is a type of malware that obtains user information without their knowledge?
**Ans: Spyware (स्पाइवेयर)**

**Malware Types:**
- **Virus** — self-replicating, attaches to programs
- **Worm** — spreads without user action
- **Trojan** — disguised as legitimate software
- **Spyware** — steals information secretly
- **Ransomware** — locks data, demands payment

### I. SYSTEM ANALYSIS & DESIGN

#### Software Testing
**Q.** Which is NOT a type of control structure testing?
(A) Equivalence analysis (B) Basis path testing (C) Loop testing (D) Conditional testing
**Ans: (A) Equivalence analysis** — This is black-box testing, not control structure testing

**Testing Types:**
- **Black Box Testing** — Testing without knowledge of internal code
- **White Box Testing** — Testing with internal code knowledge
- **Unit Testing** — Testing individual components
- **Integration Testing** — Testing combined components
- **Beta Testing** — End-user testing before final release (UAT)

**Q.** Beta testing is also known as:
**Ans: User Acceptance Testing (UAT)** or End-User Testing

#### UML
**Q.** Empty triangle notation in class diagram represents:
**Ans: Generalization (Inheritance)** — "is-a" relationship

**Q.** Filled diamond represents:
**Ans: Composition** — "part-of" relationship (strong ownership)
